OrangeHRM Test Automation with Playwright (Python)

This project uses Playwright with Python to create automated UI tests for the OrangeHRM Open Source application.
It demonstrates end-to-end testing, page object patterns, and basic test organization.

Link - https://opensource-demo.orangehrmlive.com/web/index.php/auth/login

Setup Instructions

1. Clone the repository
   git clone https://github.com/Joan-Maina/orangehrm-playwright.git
2. Install dependencies
3. Install Playwright Browsers

Running the tests:

1. py -m pytest --headed

Requirements:

- Python 3.8+
- Playwright
- pytest
